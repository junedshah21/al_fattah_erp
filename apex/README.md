# Oracle APEX application source

AL-FATTAH ERP is an independently developed Oracle APEX demonstration application (Application ID 238769).

The original application export is not approved for public distribution because hard-coded OpenAI and RapidAPI credentials were identified in a reviewed export. A sanitized export will be added only after affected keys are revoked/rotated, embedded assets and third-party rights reviewed, and external dependencies documented.

Do not commit credentials, production data, or unreviewed SQL/ZIP exports. A README is not evidence of a complete ERP schema or successful APEX import. See [Security advisory](../SECURITY.md) and [Installation guidance](../docs/INSTALLATION.md).
