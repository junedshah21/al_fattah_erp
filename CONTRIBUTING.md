# Contributing

Thank you for your interest in AL-FATTAH ERP. This project is currently a documented APEX demo, **not yet a complete installable open-source ERP product**.

- Use issues for reproducible, non-sensitive bugs and documentation suggestions.
- Never post proprietary application exports, personal records, access tokens, passwords, or database credentials.
- Describe Oracle APEX version, expected behavior and observed behavior without disclosing secrets.
- Source contributions and redistribution terms will be clarified once the owner selects and verifies an appropriate license.

No external adoption or contributions are currently claimed.
